# Offline Hafs corpus

`hafs-corpus.json` is the Uthmani Arabic text from `quran-json` 3.1.2, whose
README identifies the text source as The Noble Qur'an Encyclopedia and the
license as CC-BY-SA 4.0. It is bundled for the deterministic recognition
spike so matching does not make a network request. The original Arabic text
is retained in match results; normalization is used only for comparison.
