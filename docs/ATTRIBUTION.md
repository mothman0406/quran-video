# Quran text attribution

The canonical Arabic corpus is Tanzil Quran Text (Uthmani, version 1.1),
Copyright (C) 2007–2021 Tanzil Project, licensed under Creative Commons Attribution
3.0. It is a verbatim local copy and must not be changed. Source and updates:
<https://tanzil.net/>. The complete required Tanzil notice is retained in
`src/lib/quran/tanzil-uthmani.txt`.

Quran Foundation may provide optional translations, transliteration, or future
enrichment, but canonical Arabic display does not depend on that service.

## Saheeh International translation

The default English translation is Saheeh International, fetched at runtime
from QuranEnc.com using the `english_saheeh` translation key. QuranEnc's
republication terms require that the publisher and source (QuranEnc.com) are
clearly identified, the source version is shown when available, the content is
not modified, and updates follow the latest source version. The app preserves
the returned translation text verbatim apart from outer presentation
whitespace. Source: <https://quranenc.com/en/browse/english_saheeh> and API
documentation: <https://quranenc.com/kbd/home/api>.
